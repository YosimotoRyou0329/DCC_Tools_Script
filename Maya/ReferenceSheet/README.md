# Reference Sheet（三面図）

正面・背面・右側面・左側面の画像（最大4枚）から、モデリング用の板を自動で作るツールです。
板の作成・位置合わせ・縦横比の調整を手作業でしなくて済むようにします。

## 使い方

1. Maya上部の `DCC Launcher → Reference Sheet（三面図）` でパネルを開く（ドッキング可能）。
2. 上の4つのスロット（正面 / 背面 / 右側面 / 左側面）に画像をドロップ、または `参照`。
   画像を入れるとガイド（頭頂・足元・中心）を自動検出します。
3. `ガイド調整` タブで線をドラッグして微調整。`並べて確認` タブで頭と足の高さが揃っているか確認。
4. `身長（ガイド間）` と `板までの距離` を設定して `三面図を作成・更新`。

もう一度押すと作り直します（グループ `ReferenceSheet_GRP` を動かした位置は保持）。`削除` で板を消します。
画像・ガイド・設定はシーン（fileInfo）に保存され、パネルを開き直すと復元されます。

## ガイド線で揃える（画像ごとに頭身が違う時）

生成画像などで正面と横の頭の大きさ・目やあごの高さが合わない時に使います。

1. `ガイド線` の `追加` から「目」「あご」「肩」「腰」などを追加（`名前を入力…` で自由な名前も可）。
2. 各画像の `ガイド調整` タブで、その線を画像の目・あごの位置にドラッグ。
3. 揃えたい線を2本までチェック（追加した線は自動でチェックされ、古い線が外れます）。
4. `三面図を作成・更新`。

- `基準画像`（★）の高さが基準。ほかの画像はチェックした線が基準と**ぴったり同じ高さ**になるよう、
  拡大率と高さを画像ごとに決めます（1本 = 高さだけ、2本 = 拡大率と高さ）。
- 揃える線は **2本まで**。縦横同じ倍率のまま（画像を崩さず）完全に一致させられるのは2本までのためです。
  3本目をチェックすると、先にチェックした線が自動で外れます（頭を作る時は「目」「あご」、全身は「頭頂」「足元」など）。
- 編集中の画像には、基準画像の線が来る位置を点線で表示し、残りのずれを数値で表示します。
- `並べて確認` タブはMayaと同じ倍率・位置で並ぶので、揃い具合をその場で確認できます。
- `ガイド線をMayaのビューにも表示` で、各線の高さに同じ色の線（`RS_guide_*_CRV`）を作ります。
  どのビューから見ても水平線として見えるので、モデルをそこに合わせられます。

## 仕組み

- 板の大きさは画像の縦横比そのまま（引き伸ばしなし）。
- 全画像を「頭頂ガイド = 身長、足元ガイド = Y0、中心ガイド = 原点の軸」に揃えるよう拡大・配置。
- 板はそれぞれのカメラから見てモデルの奥に置き、裏面非表示（backface culling）。
  どのカメラから見ても、手前側の板がモデルを隠しません。
- 照明の影響を受けない surfaceShader + file テクスチャ。レンダリング・影には映りません。
- 左右反転はUVで行います（負のスケールは使わない）。板の移動・回転は個別にはロックし、動かす時はグループごと。
- `板を選択できないようにする`: ディスプレイレイヤー `ReferenceSheet_LYR` を Reference 表示に。
- 1回の作成・削除はそれぞれ1回のUndoで戻せます。

| スロット | 見る方向 | 板の位置 |
|---|---|---|
| 正面 | +Z から（Maya front） | Z = -距離 |
| 背面 | -Z から | Z = +距離 |
| 右側面 | -X から（顔が画面右向き） | X = +距離 |
| 左側面 | +X から（Maya side、顔が画面左向き） | X = -距離 |

画像の向きが逆の時は `左右反転` で合わせます。

## ガイド自動検出

透過画像はアルファ、不透明な画像は輪郭線（エッジ）から人物の範囲を推定します。
背景のグロー・グラデーションは輪郭がないため無視されます。中心は脚の輪郭の中央値です。
帽子などがある場合、頭頂ガイドは最上部（帽子）になります。必要ならドラッグで調整してください。

## 責務

- `layout.py`: 板の大きさ・配置計算、ガイド線での位置合わせ（最小二乗）、ガイド検出（Maya / Qt 非依存、テストあり）。
- `builder.py`: Mayaでの板・シェーダー・ガイド線・レイヤー作成、削除、設定の保存。
- `canvas.py`: ガイド編集・並べて確認の表示。
- `ui.py`: ドッキング可能なパネル。

## 検証

`python -m unittest tests.test_layout`（Maya不要）。Mayaでの板の表示は実機確認が必要です。
